# Crashpot

A party of tiny games for 2 to 6 players. No talking needed.

**Play:** https://fardasticmanguy-rgb.github.io/cool-game/

## How it works

1. Tap **Quick play** (or Host) and get your friends into the lobby.
2. The host picks 4, 6 or 9 games and taps Start.
3. Before each game, a box explains the rules with a countdown. Then the game starts.
4. Win games to get points. Most points at the end wins.

## إزاي تلعب

1. دوس **Quick play** وخلي صحابك يدخلوا اللوبي.
2. الهوست يختار ٤ أو ٦ أو ٩ ألعاب ويدوس Start.
3. قبل كل لعبة، في مربع بيشرح القواعد وعداد. بعدها اللعبة تبدأ.
4. اكسب الألعاب عشان تاخد نقط. اللي معاه أكتر نقط في الآخر يكسب.

## Modes

| Mode | What it is |
| --- | --- |
| 🃏 Crash Cards | Pick a card nobody else picks. Twists, ×2, Shield, Peek |
| ⚔️ Brawl | Pick a fighter. Attack, Parry, Charge or Special. Last one standing wins |
| 🙈 Hide & Seek | Hide on the map, sneak around, or hunt as the seeker |
| 🎉 Party | A mix of mini games, each with rounds and twists |
| 🎯 One game | Play one mini game for several rounds |

## The mini games

| Game | What to do |
| --- | --- |
| 🃏 Crash Cards | Pick a card nobody else picks |
| 🚦 Green Light | Wait for green, then tap fast |
| 👊 Button Masher | Tap as many times as you can |
| 🧮 Math Rush | Answer as many as you can |
| 🔍 Odd One Out | Find the different emoji |
| ⏱️ Stop at 5 | Stop the hidden clock at 5.00 |
| 🎨 Color Trap | Tap the color, not the word |
| 🤝 Grab or Share | Share with everyone, or grab it all |
| ⚖️ Pick a Side | The smaller side wins |
| 🚀 Rocket Cash | Cash out before the rocket explodes |
| 💎 Gem Mines | Dig up gems, dodge the bombs, bank in time |
| ☝️ Steady Finger | Keep your finger in a moving, shrinking circle |
| 🧠 Copy Cat | Repeat a color pattern that keeps growing |
| 🎯 Sharpshooter | Fire when the line hits the bullseye |
| 🔨 Whack-a-Mole | Smack the moles, not the bombs |

## Extras

- Emoji reactions to trash-talk without talking
- **Family friendly** mode is on by default
- Bots can fill empty seats
- **Practice vs bots** works offline
- **Online now** shows who else has the game open, and which lobby they're in
- **Invite** anyone online from your lobby, or tap **Share link** to paste it in the chat
- Fonts ship with the game, so they work on school Wi-Fi, Firefox and tablets

## Play links

`?play=<code>` opens or joins that lobby. Add `&mode=cards|brawl|hide|party|single`, or `&game=rocket` (any mini game) to start in One game mode with it. `&games=rocket,mines,whack` picks the Party games.
